# 坦克大战 Tank Battle 🎮

一个用原生 HTML + Canvas + JavaScript 编写的经典《坦克大战》网页游戏，单文件即可运行，无需任何依赖。

## 在线游玩

直接打开 `index.html`，或在浏览器中打开后即可开始游戏。

## 操作方式

| 动作 | 键盘 |
|------|------|
| 移动 | 方向键 / W A S D |
| 开火 | 空格 / J |
| 暂停 / 继续 | P |
| 开始 / 重新开始 | Enter |

移动端（触屏设备）会自动显示虚拟方向键与开火按钮。

## 玩法说明

- **保护基地** 🦅：位于屏幕底部的基地（鹰）一旦被敌人击中即游戏结束。
- **消灭敌人**：每关需要消灭所有敌人，全部消灭后自动进入下一关。
- **地形**：
  - 🧱 砖墙 —— 可被子弹摧毁
  - ⬜ 钢墙 —— 普通子弹无法摧毁（满级子弹可摧毁）
  - 🌊 河流 —— 坦克无法通过，子弹可以越过
  - 🌲 树林 —— 遮挡坦克，可自由穿行
- **道具**（随机掉落）：
  - ⭐ 星星 —— 升级火力（最多 3 级）
  - 🛡️ 护盾 —— 短暂无敌
  - ❤️ 生命 —— 增加一条命
  - 💣 手雷 —— 消灭当前所有敌人
- 满级火力可以摧毁钢墙并贯穿砖墙。

## 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node.js
npx serve .
```

然后访问 http://localhost:8080

## 技术栈

- HTML5 Canvas 渲染
- Web Audio API 音效
- 原生 JavaScript（无框架、无构建步骤）
